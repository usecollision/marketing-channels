## When to Use

Invoke when:
- Launching an ambassador or advocate program from scratch
- An existing program is a list of titles with no activation, no rituals, and no output
- Deciding who belongs in the program — selection is currently by follower count or favoritism
- Ambassadors burn out or churn because benefits and expectations are mismatched
- You need program health metrics beyond the member count
- Community members want a formal path to leadership and ownership

## Workflow

### Step 1: Define the Job and Selection Criteria
- [ ] Name the job ambassadors do: content creation, event hosting, community leadership, feedback, referrals — pick one primary
- [ ] Write selection criteria as observable behavior: product love shown in real use, activity in the community, audience or influence, alignment with brand values
- [ ] Choose the entry path: application with evidence, or invitation from observed behavior — invite-only raises status but shrinks the pool (heuristic)
- [ ] Screen for brand safety: review past public content for anything that would embarrass the brand later
- [ ] Decide cohort size from capacity: every ambassador needs management time; size the cohort to the team that will actually run it (assumption)

**Gate:** Job definition written, behavior-based criteria published, cohort size tied to capacity.

### Step 2: Design the Benefits Ladder
- [ ] Build tiers: member → advocate → ambassador → council — each tier adds responsibility and reward
- [ ] Benefits that cost little and mean much: status (badges, titles), access (product previews, founder calls), recognition (spotlights, features), events, and revenue upside
- [ ] Recognition beats cash for many advocates — but it must be visible to their peers (assumption — validate with your own cohort)
- [ ] Publish the ladder: what each tier gets and what each tier must do — hidden criteria breed resentment
- [ ] Tie tier movement to behavior, not tenure — review promotions quarterly

**Gate:** Tiered ladder published with per-tier benefits and responsibilities, promotion rules documented.

### Step 3: Build Activation Rituals
- [ ] Onboarding ritual: welcome pack, program handbook, first mission assigned within a week of joining — speed to first win predicts retention (assumption)
- [ ] First 30 days: first mission completed, introduced to the cohort, first recognition moment
- [ ] Recurring rituals: monthly challenges, quarterly summits, ambassador-only office hours, spotlight posts
- [ ] Pair new ambassadors with veterans — a buddy system raises activation
- [ ] Calendar everything; unscheduled rituals quietly stop happening

**Gate:** Onboarding flow with a first-week mission, 30-day plan, and a rituals calendar with owners.

### Step 4: Develop Community Leadership
- [ ] Train ambassadors to run things themselves: local meetups, chapter groups, support communities, content series
- [ ] Grant real ownership, not busywork — leadership development happens through responsibility
- [ ] Build the escalation path: ambassador → council → paid roles or formal partnerships for the strongest (see creator-outreach)
- [ ] Recognize leadership publicly — the community should see the path working
- [ ] Watch for the burnout signal: ambassadors doing more than they signed up for, silently

**Gate:** Leadership path documented with owned initiatives, escalation to paid roles defined.

### Step 5: Measure Program Health
- [ ] Health metrics: activation rate (joined → first mission done), activity per ambassador, cohort retention, output volume (content, events, referrals), referred revenue where applicable
- [ ] Business tie-ins: churn of ambassador-influenced customers, NPS of engaged members, support deflection — each validated with your data (assumption until proven)
- [ ] Cost per ambassador vs value produced — the program must survive a budget review
- [ ] Sentiment pulse: quarterly check-ins catch disengagement before it spreads
- [ ] Report quarterly to the company — the program's existence depends on demonstrated value

**Gate:** Dashboard live from launch, quarterly health report scheduled, cost-value review built in.

### Step 6: Govern and Offboard Well
- [ ] Code of conduct for ambassadors — they represent the brand publicly
- [ ] Conflict-of-interest rules: competing product promotions, pay-to-post disclosures
- [ ] Offboard with dignity: exits happen (life changes, priority shifts) — an alumni tier keeps goodwill
- [ ] Handle the hard cases explicitly: behavior violations get a documented process, not improvisation
- [ ] Annual reset: re-test the program's job against the company's needs; kill or pivot without nostalgia

**Gate:** Governance policy written, alumni tier defined, annual review scheduled.

## Practitioner Grounding & Decision Rules

Built from community practice (Millington, Spinks) + partnership measurement (Prussakov). Full research: practitioner-intelligence/syntheses/social.md, partnerships.md.

- **Purpose + value behaviors before perks** (Millington — FRAMEWORK, T1): ambassador programs fail when the benefit ladder precedes a defined value exchange.
- **Advocacy ≠ influencers** (Spinks — FRAMEWORK, T1): ambassadors are customers with observed behavior, not paid creators.

Decision rules:
1. IF no defined value behaviors exist THEN define them before recruiting — perks without purpose attract mercenaries (Millington — FRAMEWORK, T1).
2. IF selection is by follower count THEN switch to observed behavior (existing customers who already advocate) (Spinks — FRAMEWORK, T1).
3. IF the program can't tie ambassador activity to a business metric THEN add tracking before scaling (Prussakov — FRAMEWORK, T1).
4. IF ambassadors aren't activated within 30 days of signup THEN the onboarding is broken — activation cadence is the program (synthesis — HEURISTIC, T2).

## Metrics

- **Activated ambassadors** (performed ≥1 value behavior) per cohort (Millington — FRAMEWORK, T1).
- **Referral/advocacy revenue** attributable to ambassadors (Prussakov — FRAMEWORK, T1).

## Evaluation & QA

### Scoring Rubric
| Criteria | Score 1 | Score 3 | Score 5 |
|----------|---------|---------|---------|
| Selection | Follower count | Application form | Behavior-based criteria + brand-safety screen + capacity-sized cohort |
| Benefits | Free product for everyone | Tier labels exist | Published ladder, visible recognition, promotion rules |
| Activation | Join and vanish | Welcome pack | First-week mission + buddy system + rituals calendar |
| Leadership | Staff runs everything | Ambassadors help | Owned initiatives + escalation path to paid roles |
| Health | Member count reported | Activity tracked | Activation, retention, output, and cost-value measured |

### Common Failure Modes
- Recruiting by follower count instead of demonstrated behavior
- A benefits ladder that rewards tenure and volume but not real contribution
- No activation ritual — ambassadors join, get a title, and never do anything
- Treating ambassadors as free labor — resentment spreads fast and loudly
- No offboarding plan — an exit handled badly undoes the program's public goodwill
- Measuring size instead of activation, retention, and output
- Keeping the program alive past its usefulness because shutting it down feels ungrateful
